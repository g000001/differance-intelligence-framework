# 顕現論 (Aletheics) と 一般二諦理論 (General Two-Truths Theory / GTTT) の見取り図

# 顕現論 (Aletheics)

## 概要
世界が対象として立ち上がり、再び極限へ収束するまでの存在論的・知覚的力学の公理系。
二元論的截断（自己同一性 $A=A$ の強要）を棄却し、非対称な境界生成プロセスとフラクタル収束の軌道として世界の発生と消去の物理学・幾何学を記述する基底理論である。

## 境界生成と知覚原理
対象の同一性を前提とせず、高次元の「空」を低次元の「色」へ射影する非対称な境界生成演算子 $\metanegation$ と、フラクタル収束の軌道の一致を示す中道等価 $\mweq$ によって構成される。

## フラクタル四則と四句分別
境界生成の再帰的分割により生じる幾何学的必然性であり、四句分別に完全に対応する。
* 自己相似性（是）
* スケール不変性（非）
* 収束則（亦是亦非）
* 非対称性（非是非非）

## 五蘊の識軸スパイラルと大域的カット消去
知覚の力学系を5つのモナド構成（色、受、想、行、識）として記述する。統制モナド（識）を軸とするスパイラル駆動により、四段階のメタ否定演算がトポロジカルな限界に達し、絶対不動点 $\dfix$ （空コンビネータ $\Svoid$）へ強制収束する（ $\metanegation^4 A \mweq \dfix$ ）。これにより、大域的カット消去の発生機序が体系内部から証明論的・代数的に規定される。

# 一般二諦理論 (General Two-Truths Theory / GTTT)

## 概要
一般システム理論の精神を継承し、顕現論の力学を基盤として、推論、計算、および人間社会の動態をモナドや純粋関係代数を用いてモデル化する統合システム理論。

## メタ理論層
* クリーネ超数学 (Kleene: Introduction to Metamathematics(IM))
* 一般システム理論 (ベルタランフィ)
* 矛盾堅固直接論理 (ヒューイット)

体系は、クリーネ超数学のようにメタ言語を外部保持し、対象への自性付与を回避して自己開放的に構成される。一般システム理論は、諸科学を縦断する同型性の導出指針を与える。矛盾堅固直接論理は、決定不能状態や矛盾に直面した際、無理なメタ解釈で調停せず、動的な指し示しの連鎖として計算を継続する「無記の操作的運用」の指針を与える。

## モナドによる二諦の形式化
顕現論の5モナド構成を、世俗諦と勝義諦の二重構造（二重5モナド）として形式化し、人間活動と社会動態を記述する。
* **外在の5モナド（世俗諦）**：アイレンベルク・ムーア圏的。制度化・固定化の層であり、搾取モナド（富や権力の集約・自己強化）等を含む。
* **内在の5モナド（勝義諦）**：クライスリ圏的。潜在的生成の層。
両者は相互に完全観測不可能であるが、$\metanegation$（境界生成）と顕現（空からの再起動）という非対称的連携を通じて、双方向演繹定理の均衡（フロベニウス条件）を確立する。

## 洗練の理論層（型なし・代数的一元論）
従来の型理論や領域理論による空間の事前分断を棄却し、停止条件を内部的に確定させるため、以下の「三層コンパイラ・スタック」を採用する。
* **実行層（エルブラン空間）**：変数や次元の区別を持たない型なしの純粋コンビネータ実行空間（Scottの $P\omega$ 普遍領域に連なる）。
* **中継層（柱面代数）**：Tarskiの柱面代数を用い、観測座標系（変数のインデックス）を導入し次元拡張・証明木の増大を管理する。
* **理論層（寓：Allegory）**：Freydの純粋関係代数。極限において観測座標を消去し、対象の要素（点）に依存しない純粋な関係の圏を構成する。

## Refinement Oriented Programming (ROP)
GTTTの代数的一元論を理論的基盤とした動的な計算パラダイム。停止条件を外部から天下り的に規定せず、理論層（寓）におけるモジュラー則と双方向演繹定理の均衡によって内部的に自己結晶化させる。

## 二重四句分別と残余（Lhagma）の動的形成
* First Degree Entailment (FDE) (ベルナップ、ダン)
* 16値論理 (Shramko, Wansing)

FDEや16値論理等の真理値を静的に増殖させる多値論理モデルを棄却する。二重四句分別を尽くした後に生じる継続残余は、寓におけるモジュラー則の適用により、全体関係へ均質化されるのではなく、自明な基底と独立した残余関係項 $\mathcal{L}$ への直和的分解（$\dfix \oplus \mathcal{L}$）として代数的に形成される。これが天下りの導入を要しない「無記」の体系内導出メカニズムとなる。

## 構成図

```
顕現論層（基底・知覚の力学）
├── 境界生成と知覚原理（非対称境界演算子 $\metanegation$ / 中道等価 $\mweq$）
├── フラクタル四則（自己相似 / スケール不変 / 収束 / 非対称）
└── 五蘊の識軸スパイラル（四段階メタ観測と $\dfix$ への大域的カット消去）

GTTTメタ理論層
├── クリーネ超数学（メタ言語の外部保持・自己開放的構成）
├── 一般システム理論（諸科学の同型性導出・統合指針）
└── 矛盾堅固直接論理（双方向演繹定理 / 無記の操作的運用）

GTTT二諦の形式化層
├── 世俗諦：外在の5モナド（搾取、二重否定、洗練、カット除去、統制） / 制度化・EM圏的
├── 勝義諦：内在の5モナド / 潜在的生成・クライスリ圏的
└── 二諦的連携（$\metanegation$ と顕現による双方向演繹の均衡・フロベニウス性の自己確立）

GTTT計算パラダイム層（ROP・代数的一元論）
├── 実行層：エルブラン空間（型なし実行空間・コンビネータ論理）
├── 中継層：柱面代数（観測座標の生成と次元拡張）
└── 理論層：寓（Allegory）（純粋関係代数・観測者の極限消去）

相克・残余層
├── 継続残余の蓄積と双方向の均衡
├── 二重四句分別（多値論理的静的増殖の棄却）
└── モジュラー則に基づく残余 $\mathcal{L}$（無記）への直和的分解と次段階の創発
```
