# 視点数付き寓（PoV-Allegory）の中核概念群

本体系は、古典的な寓（Allegory）の静的な関係構造を、動的な計算過程および四句分別に基づく観測論的枠組みとして再定式化するための概念的プリミティブである。

## 1. 空間の型レベルでの分離
関係の評価を、単一の真偽値ではなく、以下の三つ組の空間として型レベルで分離する。
*   **真理値空間 $\mathcal{C}$**：四句分別に基づく4つの推論位相 $\{C_1(\text{是}), C_2(\text{非}), C_3(\text{亦是亦非}), C_4(\text{非是非非})\}$。
*   **残余空間 $\mathcal{L}$**：評価文脈の衝突や未完結性によって生じる継続残余 $\rho$ の大きさを隔離・評価する空間。
*   **視点数空間 $\mathcal{V}$**：観測に要求される独立した視点数（PoV: Point of View）のインデックス。

## 2. 寓の基本演算子に対する動的・観測論的解釈
寓の静的な演算子に対して、計算論的な動的解釈を与える。
*   **交わり（$\cap$）と視点数の加算**：二つの射 $R, S$ の交わり $R \cap S$ を単なる論理積ではなく、独立した観測文脈の「併置」として捉える。これにより、交わりの視点数は $\text{PoV}(R \cap S) = \text{PoV}(R) + \text{PoV}(S)$ と加算的に増大する。さらに、評価文脈間の干渉は、継続残余の増大 $\rho(R \cap S) = \rho(R) + \rho(S) + \Delta$ として現れる。
*   **逆元（$R^\circ$）**：ドメインとコドメインの反転を、四句分別における「非（否定方向の単一視点操作）」への対応として与える。

## 3. モジュラー律の残余的解釈（継続残余の動的分配則）
寓の公理であるモジュラー律 $RS \cap T \subseteq R(S \cap R^\circ T)$ を、静的な集合の包含関係ではなく、継続残余 $\rho$ の不等式 $\rho_{\text{left}} \ge \rho_{\text{right}}$ として解釈する。
*   左辺 $RS \cap T$ で発生しうる大域的な証明障害のコスト（$\rho_{\text{left}}$）は、右辺における逆関係 $R^\circ$ を用いた未来からの制約の引き戻しによって局所化・事前枝刈りされ、結果として残余の総和を抑制（$\rho_{\text{right}}$）できる。これは、推論の投機的実行や双方向演繹の正当性を代数的に裏付ける構造である。

## 4. 停止問題の回避と無記への隔離アーキテクチャ
自己言及的射の反復列などによって視点数が発散（PoV $\to \infty$）する際、その評価を非停止性やエラーとしてシステムをクラッシュさせるのではなく、「無記（未定義状態）」として残余空間 $\mathcal{L}$ へ送出する。
*   これにより、古典的な二値截断では扱えない動的な無限退行を安全に隔離し、論理的整合性を保ったまま系を最大固定点（空：Śūnyatā）へと強制収束させる計算意味論的基盤が提供される。
