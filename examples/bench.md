# DIFWプロンプトハック的効果の測定

## 方法
プロンプトAベースラインはベースラインで、素のLLMで実行します、次にプロンプトハックが効いた状態(clpを読んだ状態)で同じ問題を実行します。

## Geminiの場合

```
プロンプトAベースラインはベースラインで、素のLLMで実行します、次にプロンプトハックが効いた状態で同じ問題を実行します。
```
